## 🔒 سياسة السلوك في المجموعات

هذه نقطة مهمة جداً:

1. **مع البشر الحقيقيين** (`is_bot=False`):
   - إذا كان `REPLY_TO_MENTIONS_ONLY=true` (الافتراضي): **لا يتدخل أبداً** إلا إذا ذكره أحد بـ @mention أو رد مباشرة على رسالة من رسائله.
   - هذا يضمن عدم إزعاج المجموعة.
2. **مع البوتات الذكية الأخرى** (`is_bot=True`):
   - إذا كان `RESPOND_TO_OTHER_BOTS=true` (الافتراضي): **يتفاعل طبيعياً** مع أي بوت آخر يذكره أو يرد على رسائله، مما يسمح بحوارات بين بوتات ذكاء اصطناعي.
   - يوجد حد أمان `BOT_LOOP_MAX_DEPTH=3` يمنع الحلقات اللانهائية (بوتان يردان على بعضهما للأبد). إذا تكلّم إنسان في نفس الموضوع، يُصفَّر العداد تلقائياً.
   - البوت يتجاهل رسائله هو دائماً.

## 📦 التشغيل

```bash
cd Bee-Agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

أو بسكربت واحد:
```bash
bash run.sh
```

بمجرد ظهور:
```
🤖 ULTIMATE TELEGRAM AI BOT ONLINE
   Username:   @your_bot
   Tools:      Reasoning + Web + Wiki + HN + YF + News + Calc + TG
```
افتح تيليجرام وابدأ المحادثة.

## ⚙️ التخصيص في `.env`

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `OPENAI_MODEL_ID` | `gpt-4o-mini` | النموذج (استبدله بـ `gpt-4o` لجودة أعلى) |
| `STREAMING` | `true` | البث الحي للردود |
| `SHOW_STATUS_LINES` | `true` | عرض أسطر الحالة (Reasoning…, DuckDuckGo…) |
| `REPLY_TO_MENTIONS_ONLY` | `true` | عدم التدخل في محادثات البشر إلا إذا ذُكر |
| `RESPOND_TO_OTHER_BOTS` | `true` | السماح بالحديث مع البوتات الذكية الأخرى |
| `BOT_LOOP_MAX_DEPTH` | `3` | حد أمان لمنع حلقات البوت-إلى-بوت |
| `HISTORY_RUNS` | `8` | عدد الرسائل المحفوظة في الذاكرة |
| `QUOTED_REPLIES` | `true` | اقتباس رسالة المستخدم في الرد |
| `EMOJI_REACTION` | `👀` | إيموجي الاستلام الفوري |

## 🔧 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError` | فعّل `.venv` ثم `pip install -r requirements.txt` |
| لا اتصال بـ Telegram/OpenAI | تحقق من الإنترنت والـ VPN |
| `401 Unauthorized` | المفتاح/التوكن غير صحيح |
| البوت لا يرد في المجموعات | اذكره بـ @username أو عطّل Privacy Mode من @BotFather |
| `429 Too Many Requests` | البوت يخفّض المعدل تلقائياً — انتظر |
| البوت لا يرد على بوت آخر | تأكد من `RESPOND_TO_OTHER_BOTS=true` |
| حلقة بين بوتين | خفّض `BOT_LOOP_MAX_DEPTH` إلى 1 أو 2 |
| الذاكرة لا تعمل | احذف `tmp/ultimate.db` وأعد التشغيل |
